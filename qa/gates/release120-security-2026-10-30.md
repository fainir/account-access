# Build 120 security and update qualification

Build 119 is a QA candidate, not an owner handoff. A new dependency audit found CVE-2026-119284 in joserfc 1.7.5. [The upstream release](https://github.com/authlib/joserfc/releases/tag/1.7.6) adds the compact-value size check before splitting token segments. The graph now explicitly requires the patched library and locks 1.7.7; the runtime export was regenerated.
