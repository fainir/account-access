The source repair creates a private session in the single-use worker bootstrap before Security calls and before permanently dropping identity. It retains the existing descriptor allowlist, root supervisor, sandbox and library validation. Apple documents that [SessionCreate](https://developer.apple.com/documentation/security/sessioncreate(_:_:)) creates a session containing only the caller and a bootstrap subset inherited by its children; prior authorization/keychain state is discarded. This supports the observed diagnosis; the final production worker still needs Installer acceptance.

Output, exceptions, credentials, codes and website state are not retained. A hanging process group is killed after 20 seconds. Controlled fixtures are never reported READY by skipping the check.
