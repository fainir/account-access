# Setup UI review - 2026-10-29

Reviewed the local Account Access setup UI in isolated controlled-demo state. No personal accounts, passwords, verification codes, or export data were used. The import review used a synthetic row and verified that its password is not rendered.

## Results

- At 375×812 and 1440×1000, Accounts, Verification, Password sync, import review, empty state, initial loading state, and malformed-import error state fit the viewport without horizontal scrolling.
- Navigation and visible verification buttons meet a 44 px minimum target. The email setup disclosure is 44 px high. The keyboard focus outline is visible at 3 px.
- Authenticator, email, and mailbox fields have visible labels. Switching from Gmail to TLS IMAP reveals both server fields and their labels; switching to Gmail hides both together.
- Small-text contrast measured 4.79:1 for muted text, 5.13:1 for the footer link and pending badge, and 5.74:1 for account links. All reviewed text samples meet 4.5:1.
- The focused verification, mailbox, guided setup and responsive UI regression suite passes: 32 tests.
- Browser console had no page errors. The [native owner-screen regression log](native-owner-screen-2026-10-29.log) confirms connection failure offers “Reopen and check status,” which checks state without replaying setup or macOS authorization.
- No personal-site login, physical Android device, or updated installed Mac build was exercised in this review.
