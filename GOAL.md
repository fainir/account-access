# Goal for Account Access

Make Account Access production ready end to end: install and update reliably on macOS, safely import Chrome passwords, complete supported email, Android SMS and authenticator verification, and let local AI agents use only owner-approved account operations. Done when every buildable flow and release gate is verified on its real surface or precisely cut, with only exact owner actions or dated third-party waits remaining.

The first production target is the owner's Apple silicon Mac and Android phone, with local Codex and Claude Code. No recurring cloud-service budget was authorized. Use READINESS.md as the shared status ledger.
