# Goal for Account Access

Make Account Access production ready end to end: install and update reliably on macOS, import passwords once, connect reusable email, Android SMS and authenticator sources once, and let local AI agents complete later supported logins using only owner-approved account operations. Passkeys and other required owner-presence checks must remain explicit owner actions. Done when every buildable flow and release gate is verified on its real surface or precisely cut, with only exact owner actions or dated third-party waits remaining.

The first production target is the owner's Apple silicon Mac and Android phone, with local Codex and Claude Code. No recurring cloud-service budget was authorized. Use READINESS.md as the shared status ledger.
